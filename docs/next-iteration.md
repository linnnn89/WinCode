# WinCode 效率与准确性迭代

更新：2026-10-10。本文是后续任务入口，只保留当前限制、验收条件和有证据触发的候选工作。接口以[客户端使用说明](hybrid-readonly-orchestration.md)为准；实现分层见[架构与数据流](../WinCode-架构与数据流说明.md)，已完成变更见 [CHANGELOG](../CHANGELOG.md)。

## 当前状态与优先事项

`checkbox-audit` 已支持精确 name + CheckBox 选择器，兼容旧 AutomationId 模式；针对性回归及核心检查通过。混合流程仍由调用方显式启用，不自动调用模型或切换客户端默认配置。

真实应用的名称模式验收尚未闭合：在一个 CEF 设置页面中，原生 UIA 未稳定暴露业务控件。Control/Raw View 对照、MSAA 接口读取及一次授权重启均未恢复可验证的复选框集合，因此未进入原生与配方的配对试验。不能据此宣称真实适配通过、稳定性能收益或默认化验收通过，也没有证据把原生取证失败归因于名称配方。

优先定位原生取证缺口；只有新证据支持具体假设时才继续诊断，不重复重开窗口、重启应用或放宽完整性要求。CEF 的[可访问性接口说明](https://github.com/chromiumembedded/cef/blob/6478/include/cef_browser.h#L839-L865)仅提供机制线索，不证明目标应用的具体根因。

## C．真实任务验收与效率基线

### 范围与准备

- 只测试用户授权的目标应用和页面。导航按实际观察到的唯一语义控件执行；不更改业务设置。重启应用、改启动参数或环境须另获授权，不自动添加坐标或浏览器后端。
- 核对被测源码、工作区改动、磁盘交付和实际会话身份。测试期间保持实现不变，只复用一个会话；旧连接不能代替当前构建。
- 选取 2–6 个实际存在的复选框，从独立截图或用户明确陈述建立预期。无法确认的字段记 unknown，不复制配方结果作为预期。
- 冻结目标、父范围、区域 ID、名称或 ID 选择器、预期和预算。仅在页面实际存在业务摘要开关时测试条件分支；没有摘要时明确条件分支未覆盖。
- 缺少唯一身份、共同父范围、独立预期或完整原生观察时停止准备，记录 blocked/unsupported，不开始计分。

### 配对执行与通过条件

| 路径 | 执行方式 |
|---|---|
| N：原生基线 | 同一会话单次 scoped inspect 读取必要区域并独立核对控件；有摘要时先读摘要，Off 不读详情，不人为拆成逐控件读取 |
| R：客户端配方 | 调用 `readonlyUiRecipe` 或 CLI `readonly-ui`，检查完整 steps、findings、isError 和 scopeResult |

顺序为 N1 → R1 → R2 → N2。每次重新观察，采用相同 query/tree 预算和总 deadline，默认每次 15 秒；准备与预热单列，多调用共享剩余时间。

逐项检查身份、On/Off、isEnabled、checkedCount、unchecked、disabled；禁用且 On 仍计数。摘要 Off 应零详情读取。未自然出现的状态明确未覆盖，不为补齐组合修改应用设置。

正例完成后做一次缺失父范围反例，要求范围失败、无 findings、无整窗回退；最后检查页面状态保持及自有进程清理。四次正例、范围反例、状态保持和清理全部成立，才判定该案例通过。截图仅辅助独立预期，不能替代原生状态。

### 成本与停止条件

- 保留全部尝试、失败和人工等待。分别记录调用方请求、内部读取、Helper 启动、结果文件读取、墙钟时间和输出字节；缺少 token usage 就记 unknown。
- 准备阶段被阻断与已启动试验失败分开计数。两对观察只支持适用性和粗略成本判断，不报告 P95、显著性或稳定收益比例。
- 结果不符、未经请求的动作、目标变化或清理失败即停止性能试验。超时不自动重放；不边修改实现边验收。
- 一轮最多 20 次原生 UI 请求、20 分钟主动操作；达到上限后保留证据并停止。后续轮次须有新证据和明确范围。
- 原始截图、窗口内容、账号信息、机器路径和完整日志只保存在被忽略的本地 `test-tmp/`，不提交或作为 PR 附件上传。公开报告仅保留去标识后的行为、结果和限制。

## D．测量后才决定的优化

| 已确认的瓶颈或需求 | 最小候选改动与进入条件 |
|---|---|
| 原生逐属性读取占主要时间 | 先分离启动、定位、属性读取耗时，再评估单请求内批量读取；不新增全局 COM 缓存 |
| 首次发现被无关节点缺口误拒绝 | 先取得具体误拒绝复现；保留缺口，不把部分搜索的单候选当全局唯一 |
| 多层区域导致重复拼装路径 | 候选路径必须来自实际观察，下一请求重新验证；不预建递归导航引擎 |
| 真实任务需要选择项或文本数值 | 先定义控件、字段与独立预期，再按一种结果类型扩展 |
| 同名按钮或输入框妨碍授权操作 | 单独验收 click/type 父范围、旧 Host 拒绝、旁支保持和未知结果不重放 |

| 录制提示窗或托盘间歇失败 | 曾出现 `Recording indicator could not be displayed`，根因未确认；先取得底层异常或初始化耗时，不绕过提示窗或盲重试 |
| SDK 突发监听器警告 | 历史负载后监听器恢复，未证明泄漏；普通负载复现后再调查，不抬高阈值遮掩 |
| 特殊环境 | 长时运行、动态 MSBuild 输入、异常退出清理、权限、DPI 和 Explorer 重启按实际环境触发验证 |
| 发布与部署 | 源码合并、磁盘构建、安装 Skill 和当前连接分别验收；合并不代表已部署或已发布 Release |

## 维护方式
